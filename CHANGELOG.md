# Changelog

Notable public changes to Turnkey are recorded here.

## 0.1.0 - 2026-07-22

### Added

- Public contribution, conduct, security, support, governance, and release
  policies.
- Project-front-door README with source quickstart, documentation map, project
  status, and DeepWiki preparation.

## 0.1.0 source preview

- CPU-first paired evaluation and audit workflow.
- External detector loading and typed runtime providers.
- Inspectable four-file public artifact bundle.
- Example detector, attack, judge, dataset, and backend integrations.
- Canonical documentation and four executable learning notebooks.

This source preview has not been published as the functional PyPI release. The
`turnkey==0.0.1` package remains a namespace reservation.
