# Governance

Turnkey is maintainer-led. Maintainers define the product boundary, approve
public interfaces and release claims, review licensing and safety constraints,
and decide when a development commit is ready for the stable branch.

Routine fixes and documentation improvements may be accepted after maintainer
review and passing relevant gates. Changes to artifact schemas, extension APIs,
security guidance, licensing, repository ownership, release policy, or claims
of scientific reproduction require explicit owner approval.

Technical disagreements should be resolved using current code, reproducible
tests, public contracts, and user outcomes as primary evidence. When evidence is
incomplete, document the uncertainty rather than promoting an assumption to a
project guarantee.

The maintainer may delegate review or operational responsibilities, but that
does not silently transfer project ownership or release authority.
