# Security Policy

## Report a vulnerability

Do not open a public issue for a vulnerability, leaked credential, private
dataset, unsafe redaction behavior, or an exploit that could put users at risk.
Use GitHub private vulnerability reporting when it is available. Otherwise,
contact the maintainer through a private contact method published on the
[maintainer's GitHub profile](https://github.com/lijrjyan).

Include the affected version or commit, impact, the smallest safe reproduction,
and a suggested mitigation when possible. Remove real credentials, personal
data, private prompts, and proprietary model or dataset content from all
attachments.

## Scope

Security reports may cover the Turnkey CLI and library, component loading,
provider or backend integrations, artifact redaction, cache behavior, dependency
risk, and repository automation. Third-party model and dataset vulnerabilities
should also be reported to their upstream maintainers when appropriate.

Turnkey is an early source preview and does not currently publish a fixed
security-support window. Maintainers will assess reports based on severity and
available evidence, coordinate disclosure where practical, and document a
released fix or mitigation before public detail is added.
