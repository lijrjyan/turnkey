# Support

Start with the [installation guide](docs/get-started/installation.md),
[ten-minute quickstart](docs/get-started/quickstart.md), and
[debugging guide](docs/guides/debug-a-run.md). The CLI's `--help` output is the
authoritative option reference for the commit you installed.

Use GitHub Issues for reproducible runtime bugs, packaging problems,
documentation gaps, or focused feature proposals. Website navigation,
accessibility, and learning-site deployment belong in the
[`turnkey-site`](https://github.com/lijrjyan/turnkey-site) issue tracker.

A useful report includes the exact Turnkey commit or version, operating system,
Python version, configuration with secrets removed, smallest reproduction,
expected result, actual result, and sanitized output. State whether the path is
CPU/fake, GPU/local-model, or a live remote integration.

Do not attach credentials, private prompts, unpublished datasets, personal
data, model caches, or unredacted run bundles. Follow [SECURITY.md](SECURITY.md)
for sensitive reports.

The project does not currently promise a response-time service level. Community
support and maintenance are best effort.
